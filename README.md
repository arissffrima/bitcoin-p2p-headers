# bitcoin-p2p-headers

> headers · spv-shaped · stub

[![Rust 1.75+](https://img.shields.io/badge/rust-1.75+-DEA584)](https://www.rust-lang.org)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)
[![Build](https://img.shields.io/badge/build-passing-brightgreen)]()

Bitcoin headers helper — stub height, local vault.

## Features

- BTC path m/84'/0'/0'
- Deterministic digest (stdlib, no crates)
- Vault + account derive
- cargo test covers keys and wallet

## Prerequisites

- Rust 1.75+
- Git

## Getting Started

```bash
git clone <repo-url>
cd bitcoin-p2p-headers
cargo build --release
./target/release/bitcoin-p2p-headers --help
```

## Tests

```bash
cargo test
```

## Project Structure

```
src/main.rs
src/lib.rs
src/digest.rs
src/wallet.rs
```

SPV notes search p2p-headers, not bitcoin-light-client.
